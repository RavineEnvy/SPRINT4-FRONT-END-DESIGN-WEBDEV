# Sprint Front-End / Web Development - 04

Projeto web desenvolvido como parte da avaliação da Sprint 04.

---

## Tecnologias Utilizadas

- **Next.js** (App Router)
- **React**
- **JavaScript** (ES6+)
- **CSS3 / PostCSS**
- **ESLint**
- **Node.js & npm**
- **Hooks nativos e customizados** (ex.: `useAutenticacao`)
- **LocalStorage** (persistência de dados de autenticação e histórico de sorteios)

---

## Pré-requisitos

Antes de executar o projeto, certifique-se de que possui as seguintes ferramentas instaladas:

- [Git](https://git-scm.com/)
- [Node.js](https://nodejs.org/)

---

## Como Executar o Projeto

### 1. Clonar o repositório

No terminal, execute:

```bash
git clone https://github.com/RavineEnvy/SPRINT4-FRONT-END-DESIGN-WEBDEV.git
```

### 2. Acessar a pasta do projeto

```bash
cd SPRINT4-FRONT-END-DESIGN-WEBDEV
```

### 3. Instalar as dependências

Execute o comando:

```bash
npm install
```

### 4. Executar o projeto

Inicie o servidor de desenvolvimento:

```bash
npm run dev
```

### 5. Acessar no navegador

Após iniciar o servidor, copie o endereço exibido no terminal (geralmente `http://localhost:3000`) e cole-o no navegador.

---

## 6. Utilizadores e Senhas para Teste (Login)

O sistema possui duas formas de acesso para facilitar a correção e os testes:

### Opção A: Conta de Administrador Padrão

Utilize as credenciais de teste configuradas no sistema:

- **Utilizador:** `admin`
- **Palavra-passe:** `123456`

### Opção B: Criar um Novo Utilizador (Registo)

Se preferir testar o fluxo de registo:

1. Na tela inicial de login, clique no botão para criar uma nova conta.
2. Insira o nome de utilizador e a palavra-passe desejados.
3. Clique em **"Cadastrar Conta"**.

Os dados serão armazenados no `LocalStorage` do navegador e poderão ser utilizados imediatamente para iniciar sessão.
